# todoApp

vercelにてデプロイ → https://todo-app-puce-tau-26.vercel.app/

# コーディング規約

- ネームドエクスポートを使用すること<br>
  https://engineering.linecorp.com/ja/blog/you-dont-need-default-export

- UI部品は`Material-UI`を使用し、スタイルやレイアウトは`Tailwind CSS`を使用すること

# ブランチルール

- `developer`ブランチから切って開発すること
- マージリクエスト先も`developer`
- 機能追加: `feature/`
- テストコード: `test/`
